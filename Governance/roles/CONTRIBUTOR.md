# Contributor Role

## Purpose

The Contributor role recognizes individuals who actively contribute to TeachLink Mobile. Contributors are the foundation of the project, providing code, documentation, design, testing, community support, and other valuable work.

## Who Is a Contributor

Anyone who has made **one or more** merged contributions to the TeachLink Mobile organization (code, documentation, design, triage, community support, etc.) is a Contributor.

- No formal appointment required—status is earned through contribution.
- Contributions are tracked via GitHub (commits, PRs, issues, reviews, discussions).
- Contributor status is automatic and perpetual once earned.

## Rights & Expectations

### Rights

| Right | Description |
|-------|-------------|
| **Submit contributions** | Open issues, PRs, and propose changes |
| **Participate in discussions** | Comment on issues, PRs, RFCs, and governance proposals |
| **Request reviews** | Tag reviewers and maintainers for feedback |
| **Access public resources** | All public repos, docs, CI, and community channels |
| **Attribution** | Listed in CONTRIBUTORS.md and release notes |
| **Nominate for roles** | Can nominate themselves or others for Reviewer, Triager, Committer, etc. |

### Expectations

| Expectation | Description |
|-------------|-------------|
| **Follow Code of Conduct** | Adhere to `CODE_OF_CONDUCT.md` in all interactions |
| **Follow contribution guidelines** | Follow `CONTRIBUTING.md` for PRs, issues, and commits |
| **Respect review process** | Respond to review feedback; iterate constructively |
| **License contributions** | All contributions licensed under project license (MIT) |
| **Maintain quality** | Write tests, update docs, follow code style |

## How to Become a Contributor

1. **Find an issue** or propose a new improvement
2. **Follow CONTRIBUTING.md** for setup, branching, commits, and PR process
3. **Submit a PR** (or multiple PRs)
4. **Address review feedback** until approved
5. **Merge** — you're now a Contributor!

No invitation, approval, or ceremony required. First merged PR = Contributor.

## Recognition

- **CONTRIBUTORS.md**: Auto-generated list of all contributors
- **Release notes**: Contributors credited per release
- **Governance/RECOGNITION.md**: Describes recognition programs (swag, badges, etc.)
- **GitHub profile**: Contributor badge on TeachLink Mobile organization

## Progression

Contributors may progress to other roles:

| Next Role | Typical Path |
|-----------|--------------|
| **Reviewer** | Consistent high-quality reviews; nominated by Maintainer/Reviewer |
| **Triager** | Active issue triage; nominated by Maintainer/Triager |
| **Committer** | Sustained high-quality PRs; Maintainer nomination + consensus |
| **Working Group Lead** | Lead a focused initiative; Maintainer appointment |

There is no required timeline—progression is based on demonstrated impact and community trust.
